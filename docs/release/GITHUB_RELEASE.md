# GitHub 发布建议

## 当前仓库状态

公开分支只保留可构建的源码、测试、fork 依赖和必要的当前文档。`audit-evidence/`、
`docs/audit/` 和 `docs/backtesting/reports/` 是本地/私有审计归档，均被忽略，不进入
GitHub 构建分支。

## 推荐发布形态

1. GitHub 分支保留源码、测试、fork 基线和当前计划。
2. 完整审计证据放独立私有归档，不随构建分支增长。
3. 部署服务器只从该分支安装依赖并执行构建，不依赖任何审计附件。
4. 若需要公开某次审计，单独制作脱敏 Release 附件，不把原始证据重新加入源码历史。

## 发布前检查

发布前确认：

- 没有账户凭据、Cookie、token、storage state 或私有 workspace 标识；
- 没有本机绝对路径和临时端口记录；
- 没有 `dist/`、日志、PID、浏览器 profile 等可再生产物；
- 所有公开报告链接都指向当前 `docs/` 结构；
- 构建、测试和静态独立性检查通过。
